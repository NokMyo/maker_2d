# 르엘라 프렐류드 (Leella Prelude)

**2D 횡스크롤 액션 RPG를 코딩 없이 만들기 위한 전용 게임 제작 도구.**

르엘라 프렐류드는 RPG Maker처럼 콘텐츠를 조립하는 방식으로, 메이플스토리형 플랫폼 RPG와 던전앤파이터형 벨트스크롤 액션 RPG를 제작하는 것을 목표로 합니다.

## 첫 번째 목표

초기 버전은 **메이플형 2D 횡스크롤 플랫폼 RPG 제작**에 집중합니다.

- 맵/발판 편집
- 플레이어 시작 위치
- NPC/몬스터/포탈 배치
- 캐릭터 이동·점프·공격
- 스킬/히트박스 데이터
- 이벤트 명령
- 즉시 테스트 실행

## 구조

- `src/Leella.Prelude.Editor` — 데스크톱 제작 도구
- `src/Leella.Prelude.Core` — 프로젝트/맵/엔티티 데이터 모델
- `samples` — 예제 프로젝트
- `docs` — 설계 문서

## 원칙

> 새 프로젝트를 만들면 이미 움직이고 공격할 수 있는 작은 게임이 열린다.

범용 엔진을 만드는 것이 아니라, **횡스크롤 액션 RPG 제작에 필요한 기능을 처음부터 제공하는 도구**를 지향합니다.
