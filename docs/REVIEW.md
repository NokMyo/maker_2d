## 검증 범위

`tests/editor_tests.asm`는 기본 프로젝트 초기화, 실제 Windows 창의 클릭 좌표, 장면 실행 취소/다시 실행, 텍스트 입력 중 단축키 억제, 프로젝트 왕복 저장, 잘린 파일 로드 후 상태 보존, 실행 파일명 검증, 이벤트 미리보기의 레지스터 보존을 확인합니다.

`tests/runtime_tests.asm`는 몬스터 생존/처치와 보상, 아이템 지급 뒤 이벤트 이어 실행, 잘못된 분기 종료, 레벨 상승과 재로드, 잘못된 맵/잘린 세이브에 대한 상태 보존을 확인합니다. 숫자 종료 코드는 실패한 ASSERT_EQ의 마지막 인수입니다.

CI는 두 테스트 실행 후 에디터 내보내기와 생성된 게임의 초기화도 실행하며 각 프로세스에 30초 제한을 둡니다. 전체 수동 게임 플레이나 모든 자산 파일 조합을 검증한 것은 아닙니다.

## 남은 설계·기능 제약

- 이미지가 그릴 때마다 파일에서 로드됩니다. 자산 캐시와 이중 버퍼 렌더링은 별도 개선이 필요합니다.
- 저장에는 프로젝트 고유 ID, 체크포인트 좌표, 처치한 몬스터 상태가 없습니다. DB 개수가 같은 다른 프로젝트의 세이브까지 식별하지는 못합니다.
- 장면 실행 취소는 한 단계이며 DB·설정 변경은 포함하지 않습니다.
- 이름 입력은 현재 ASCII 문자만 처리합니다. 한국어 등 다국어 입력에는 Unicode 기반 Win32 API와 입력 방식 정비가 필요합니다.
- 프로젝트 파일/Assets 위치는 작업 폴더 기준이며, 프로젝트 선택·이동 UI와 구버전 자동 변환은 없습니다.
- 애니메이션 루프·방향·공격 시작 시점 동기화, 맵별 음악 선택 등 일부 데이터 필드의 동작은 아직 제한적입니다.
- 빌드는 독립 런타임과 프로젝트·자산을 묶는 방식입니다. 별도의 게임별 기계어 생성기는 아닙니다.
- 기존 릴리스 워크플로는 v0.0.1 태그를 강제로 옮기는 구성이므로, 이 검토에서는 실행하거나 수정하지 않았습니다. 정식 배포 체계 개편 시 불변 버전 태그와 검증된 바이너리 첨부가 필요합니다.
